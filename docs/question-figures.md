# 题库配图（2026-10-20）

这批配图来自 `数学精选题.docx`，用于补全题库中题干提到“如图/下图/图中”但没有图片的 31 道题。

## 结果

- 源 DOCX 中提取到 **30 张单题配图**
- 题库中 **31 道**题被标记为缺图
- 其中 3 组同图变体复用同一张原图：
  - 频率分布直方图：`q_d25c8a14c8a2`、`q_58060945b149`
  - 圆锥/圆面图：`q_7b5102f3bdce`、`q_c1188189c414`
  - 四棱锥图：`q_52770d7ad875`、`q_d83e8daf558c`
- `q_9af187b4b9d0`（圆锥 AB=4、SA=6）在源 DOCX 中没有对应图，按题干重绘了一张示意图
- 最终使用 **28 张图**（27 张 DOCX 原图 + 1 张重绘示意图）

## 文件

```text
data/
  figure_map.json          # 题目 ID -> 配图
  figures/                 # 28 张 PNG
```

`figure_map.json` 的路径相对仓库根目录。

手机版同时内置于：

```text
mobile/assets/figure_map.json
mobile/assets/figures/
```

## 匹配规则

- 优先按题干中的来源题号（如“86.”、“188.”）直接匹配
- 其次按题干中的几何对象、点/线关系和子问题匹配
- 同图变体复用同一张原图
- 源 DOCX 中无对应图的 1 道圆锥题按题干重绘，未使用不相符的图

## 桌面版说明

桌面版 v1.2 已支持题目配图：

- `data/questions.json` 中 31 道题已直接写入 `image_base64`，无需额外迁移
- 编辑器右侧显示配图预览，可选择/更换/清除图片
- 题库列表显示“配图/缺图”标记
- 导出 Word 时自动嵌入配图；缺图题会在试卷中明确写出“配图缺失”

手机版会在首次启动/升级时自动把 `mobile/assets/figures` 写入应用私有 `questions.json`，并写入 `figures_seeded` 标记，避免覆盖用户自己补的图或重复回填。
